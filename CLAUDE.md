# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this project is

This isn't a software project. It's a working space for building an **AI Strategy Brief** step by step, while the user works through the **AI Leadership** course on OpenAI Academy. There's nothing to build, lint or test. The brief is based on work the user selects, and it should help them recommend what moves forward and how.

## Deliverables

1. **An adaptable six-month roadmap** that puts up to three AI opportunities in order: **First**, **Next** and **Later**.
2. **The First opportunity developed into a priority AI initiative**, covering:
   - business value and evidence
   - ownership and governance
   - AI and human responsibilities
   - workflow and testing requirements
   - a 30/60/90-day adoption plan
   - ongoing support and maintenance
3. **A final recommendation** for sponsors and cross-functional partners. It combines the reviewed decisions into a short answer to four questions: what should happen first, why it matters, what it needs, and which approval, resource or action comes next.

## Rules

- **Sources:** use only information in this project or information the user has approved. Don't search the web, and don't fill gaps from general knowledge.
- **Never invent** evidence, policies, approvals, owners, dates or results.
- **Labels:** mark every item as an **Assumption**, a **Proposal** or an **Unresolved question**, as appropriate.
- **Carry decisions forward:** reuse decisions the user has already reviewed in later steps, and point out any conflict with them instead of quietly resolving it.
- **One step at a time:** do only the step the current course activity asks for. Don't jump ahead to later sections.
- **Missing information:** if something essential is missing, ask all the needed questions in one message, then stop and wait for answers.
- **Human review stays visible:** show which parts need a human decision or review. Don't mark anything **Reviewed** until the user explicitly approves it.
